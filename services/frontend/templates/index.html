Lab Viva Voce & Demonstration Cheatsheet

Key Kubectl Commands:
# Check all cluster objects
kubectl get all -n microservices-lab

# Check replicas & autoscaler
kubectl get hpa -n microservices-lab

# Demonstrate Self-Healing (Kill a pod):
kubectl delete pod -l app=frontend-service -n microservices-lab
kubectl get pods -n microservices-lab -w
Lab Evaluation Points:
  • Loose Coupling: If Product Service is scaled or restarted, Order Service and UI remain functional.
  • Stateful Persistence: Orders are stored in PostgreSQL on a Kubernetes PersistentVolumeClaim (PVC).
  • Internal DNS: Services communicate using Kubernetes DNS names (product-service:5001).
  • Self-Healing: Kubernetes automatically replaces crashed pods according to the Deployment replica specification.
