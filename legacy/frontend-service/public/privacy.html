Privacy Policy

Last updated: October 11, 2026 • Production Compliance Version 1.2

1. Overview and Scope

This Privacy Policy outlines how the Cloud-Native Microservices Platform ("the Platform", "we", "our") handles system telemetry, diagnostic records, and runtime interaction data generated when users interact with our distributed microservices environment and associated endpoints.

2. Data Collection and Diagnostic Logging

The Platform collects strictly technical and operational telemetry to ensure high availability, automated load balancing, and container orchestration health. We collect:

  • Protocol Telemetry: HTTP request methods, targeted REST endpoints (such as /api/users and /api/products), response latency in milliseconds, and HTTP response codes.
  • Cluster State Metadata: Serving pod identifiers, container IP addresses, node mappings, and Horizontal Pod Autoscaler utilization metrics.
  • Local Diagnostics: Ephemeral browser session indicators used to preserve diagnostic mode selections (such as Live Cluster Mode versus Offline Evaluation Mode).

3. Purpose of Data Processing

Data gathered via the Platform is processed exclusively for:

  • Maintaining continuous service availability and verifying Kubernetes liveness/readiness probes.
  • Evaluating system performance, packet routing efficiency, and ingress proxy latency.
  • Demonstrating containerized service discovery and fault-tolerant architecture.

We do not sell, rent, or monetize any diagnostic telemetry or user query records.

4. Storage and Data Retention

Request logs and diagnostic outputs generated in the interactive console are processed in memory and retained ephemerally for the duration of the operational session. Persistent database records are maintained on dedicated Kubernetes PersistentVolume storage within the cluster boundary.

5. Security Controls

Our infrastructure enforces container isolation using Linux kernel cgroups and namespaces, least-privilege non-root execution profiles (UID 10001), TLS termination at ingress, and declarative role-based access control (RBAC).

6. Inquiries and Contact

For questions regarding this policy or the operational infrastructure, please open an issue in the official GitHub Repository.
