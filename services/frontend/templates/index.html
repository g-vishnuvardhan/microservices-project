YOUR COLLEGE WALKTHROUGH

A demo with a clear story.

Show the application first, then explain the infrastructure behind it.

  1. Browse and place an order

    Filter the catalog, add two products and change a quantity. Place the order and explain that the order service validates prices before storing the bill.

  2. Show persistent order history

    Open Order history. Refresh the browser. In Docker or Kubernetes mode, restart the order service and show that the order remains in PostgreSQL.

  3. Trace a request across services

    Open Live inspector. Explain the frontend gateway, internal service DNS, responding hosts and measured latency. A local demo uses SQLite and has no Kubernetes pods.

  4. Demonstrate Kubernetes recovery

    In Kubernetes mode only, watch pods in a terminal and delete a frontend pod. The Deployment restores its desired replica count. Record the new pod name.

    kubectl get pods -n microservices-lab -w

  5. Explain autoscaling honestly

    Verify Metrics Server with kubectl top pods. Run the supplied traffic script, then watch HPA. Scaling depends on sustained CPU load and available metrics.

    kubectl get hpa -n microservices-lab -w
