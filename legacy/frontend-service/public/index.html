Distributed System Topology & Component Specifications

Standardized microservice decomposition following 12-factor cloud-native architectural patterns.

Frontend & Ingress Tier

Nginx 1.25 Alpine reverse proxy intercepting client traffic and resolving internal DNS targets.

  • Port 80 (Internal) • NodePort 30080 (External)
  • Path routing: /api/users & /api/products
  • Multi-stage Docker packaging (~22 MB image)

User Identity Microservice

Spring Boot 3.4 REST service providing identity management, user lookup, and RBAC.

  • Java 25 runtime with Eclipse Temurin base
  • Port 8081 • 2 active pod replicas
  • Actuator health probes at /actuator/health

Product Catalog Microservice

Spring Boot 3.4 REST service managing inventory items, prices, and stock reservation.

  • Java 25 runtime with Maven multi-stage build
  • Port 8082 • 2 active pod replicas
  • Zero-downtime rolling update deployment strategy

Autoscaling & Resilience

Horizontal Pod Autoscaler dynamically maintaining cluster stability under traffic load.

  • Target CPU utilization threshold: 50%
  • Replica scaling boundaries: 2 to 5 pods
  • Automated self-healing on container crash
